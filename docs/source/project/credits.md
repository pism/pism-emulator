## Related projects

- **[PISM](https://www.pism.io)**: the ice sheet model whose ensembles the
  emulators learn.
- **[pism-terra](https://github.com/pism/pism-terra)**: staging and running
  PISM glacier and ice sheet simulations; these docs follow its layout.
- **[xDEM](https://xdem.readthedocs.io)**: the documentation structure both
  projects borrow.
- **[cmglaciology](https://pypi.org/project/cmglaciology/)**: colormaps for
  glaciology, used for speed maps.
